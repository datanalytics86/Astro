# Astro Perfil

App web que genera un perfil astrológico básico y una proyección de próximos meses/años usando:
- Fecha de nacimiento
- Hora de nacimiento
- Fecha actual de referencia
- Horizonte de proyección (6 a 60 meses)

## Qué muestra
- Rasgo principal según signo zodiacal.
- Influencia general según franja horaria de nacimiento.
- Rasgos por temática:
  - Dinero
  - Finanzas
  - Amor
  - Trabajo
- Proyección temporal por etapas (trimestres o semestres) para próximos meses/años.

## Uso local
1. Abre `index.html` en el navegador.
2. Ingresa fecha y hora de nacimiento.
3. Presiona **Calcular perfil y proyección**.
4. Ajusta fecha actual y horizonte para recalcular la proyección.

## Previsualizar en GitHub (GitHub Pages)
1. Sube este proyecto a un repositorio en GitHub.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, elige:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (o la rama que uses) y carpeta `/ (root)`
4. Guarda los cambios y espera 1–3 minutos.
5. GitHub te dará una URL similar a:
   - `https://TU-USUARIO.github.io/NOMBRE-REPO/`

### Nota importante
Como este proyecto usa archivos estáticos (`index.html`, `styles.css`, `script.js`), GitHub Pages lo publica sin configuración extra.

## Nota
La proyección es orientativa y de entretenimiento; no reemplaza una lectura astrológica profesional.
